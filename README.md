# Website Security Assessment Report

## Target Website
https://www.gladyssaloon.com/

## Objective
This project analyzes a public website to identify common security weaknesses and present them in a professional, business-friendly manner.

## Scope
- Public-facing pages only  
- Passive analysis (no attacks)  
- Ethical security assessment

## Tools Used
- Nmap  
- OWASP ZAP (Passive Scan)  
- Browser Developer Tools  
- Canva

## Key Findings

### High Risk
- Missing security headers  
- No Content Security Policy (CSP)

### Medium Risk
- Outdated PHP version  
- Information disclosure
  
### Low Risk
- Third-party cookies  
- Open ports

## Overall Risk Level
Medium to High  

## Ethical Note
No exploitation or harmful testing was performed.
